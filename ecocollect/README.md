# EcoCollect App

Smart Municipal Waste Collection & Dispatch Platform built with Next.js 16 (App Router), React 19, and Tailwind CSS v4.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build standalone production container
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the portal locally.
